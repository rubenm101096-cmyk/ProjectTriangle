# ProjectTriangle

## Arcade puzzle game made with Godot (GDScript). It is a remake of a game I originally built in Unity right after finishing university.

## Gameplay
The board is a grid of triangles.
Each turn, 3 random pieces appear, each made of small triangles.
Drag and drop a piece onto the board to fill cells and score points.
When a triangle is completely filled, it disappears, freeing up space.
The game ends when none of the available pieces fit on the board.

## How to run
Install Godot 3.x (the project uses the Godot 3 project format).\
Clone the repository:\
   git clone https://github.com/rubenm101096-cmyk/ProjectTriangle.git \
Open Godot, choose Import, and select project.godot.
Press F5 to play (the main scene is Scenes/MainMenu.tscn).

or

Play the build uploaded on itch.io: https://rubenmartinez.itch.io/triangle
